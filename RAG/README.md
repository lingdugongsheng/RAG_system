
# 🔍 RAG 检索增强生成系统

基于 **LangChain + Chroma + DeepSeek** 的完整 RAG (Retrieval-Augmented Generation) 实现。  
支持文档加载、智能分割、语义去重、向量存储与相似度检索，并提供多轮对话、查询改写和置信度评估。

## ✨ 核心功能
- 📄 **文档处理流水线**：加载、分割、去重、向量化一条龙
- 🔄 **双重去重机制**：精确哈希去重 + 语义相似度去重
- 📦 **可配置向量存储**：支持内存或 Chroma 磁盘持久化
- 🧠 **查询改写**：根据对话历史自动解析指代，生成独立查询
- 📊 **置信度评分**：LLM 对回答质量进行 0~1 打分
- 🗂️ **多集合管理**：可创建、加载、删除多个索引集合

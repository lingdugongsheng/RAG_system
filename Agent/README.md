
# 🎧 多代理智能客服系统

基于 **LangGraph + LangChain + DeepSeek** 的多代理协作客服系统。  
能够自动分类用户意图，并将问题路由至对应的专业 Agent（技术支持、订单服务、产品咨询、通用对话），
每个 Agent 拥有专有工具，最终通过质量检查确保服务质量，必要时自动升级为人工客服。

## ✨ 核心功能
- 🧭 **意图分类**：LLM 分析用户意图，支持 tech_support、order_service、product_consult、general_chat、escalate
- 🤖 **五个专业 Agent**：每个 Agent 配备专属工具和角色提示
- 🛠️ **可扩展工具集**：订单查询、物流跟踪、产品搜索、FAQ 搜索、预算推荐
- ✅ **质量检查闭环**：自动评估回复质量，低分或需升级时追加人工提示
- 🔁 **智能路由**：意图置信度低时交由通用对话 Agent 再次理解
- 💾 **对话历史维护**：贯穿所有节点，支持多轮指代消解

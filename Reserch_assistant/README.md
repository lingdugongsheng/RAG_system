

# 📚 智能研究助手系统

一个基于 **LangGraph + Pydantic + DeepSeek** 的自动化研究流水线。  
只需输入一个研究主题，系统将自主完成规划、资料搜索、信息分析、报告撰写和质量迭代优化，
输出包含摘要、章节、结论、参考文献的结构化研究报告。

## ✨ 核心功能
- 📋 **自动规划**：LLM 生成研究大纲（标题、章节、关键问题）
- 🌐 **资料搜索**：模拟学术数据库与网络新闻检索
- 🔬 **深度分析**：提取关键发现、证据、信息缺口，支持迭代优化
- 🧩 **章节草稿生成**：为每个章节撰写 150-300 字内容
- 📄 **结构化报告**：整合为 Markdown 格式，含标题、摘要、发现、结论、建议、参考文献
- 🔍 **质量检查与迭代**：评估报告质量（0-10 分），不达标时自动重新收集资料并优化
- ⚡ **容错重试**：LLM 调用带自动重试机制，避免临时失败中断流程
